## 1. Introduction

Hospitals handle a large amount of daily information related to patients, doctors, appointments, and bed availability. Managing this information manually using paper records or basic spreadsheets often leads to confusion, delays, and errors.

The **Hospital Management Dashboard** is a simple web-based application designed to help hospital staff manage basic hospital operations through an easy-to-use interface. This project is developed using **HTML, CSS, and JavaScript**, and is intended to demonstrate how front-end web technologies can be used to build a functional and interactive dashboard system.

---

## 2. Objective

The main objectives of this project are:

- To design a clean and simple dashboard for managing hospital-related data.
- To allow hospital staff to add, view, update, and delete patient records.
- To maintain basic doctor information and their availability.
- To manage appointment scheduling between patients and doctors.
- To display key statistics (total patients, doctors, appointments, available beds) on a summary dashboard.
- To provide hands-on experience in front-end web development using HTML, CSS, and JavaScript.

---

## 3. Scope of the Project

This project is a **front-end based system** suitable for academic demonstration. The scope includes:

- A dashboard homepage showing quick statistics.
- A patient management section (add/view/edit/delete patient details).
- A doctor management section (add/view doctor details and specialization).
- An appointment booking section linking patients with doctors.
- Basic data storage using the browser's **Local Storage**, so data is not lost on page refresh.

**Out of scope** (can be mentioned as future enhancements): server-side database, user login/authentication, billing system, and real-time notifications.

---

## 4. Existing System

Most small clinics and hospitals still rely on registers, paper files, or basic Excel sheets to maintain patient and doctor records. This leads to:

- Difficulty in searching old records.
- Risk of losing important data.
- No quick overview of hospital statistics.
- Manual and time-consuming appointment scheduling.

---

## 5. Proposed System

The proposed Hospital Management Dashboard overcomes the above problems by providing:

- A **centralized digital dashboard** to view all key information at a glance.
- **Easy forms** to add and manage patient and doctor data.
- **Instant search and filter** options for records.
- **Simple appointment scheduler** to assign doctors to patients.
- Data saved locally in the browser, so no internet or server setup is required to run the project.

## 7. Modules

1. **Dashboard (Home) Module**
   - Displays total number of patients, doctors, appointments, and available beds.

2. **Patient Management Module**
   - Add new patient (name, age, gender, disease, contact number).
   - View list of all patients in a table.
   - Edit or delete patient records.

3. **Doctor Management Module**
   - Add doctor details (name, specialization, availability).
   - View and manage doctor list.

4. **Appointment Module**
   - Book an appointment by selecting a patient and doctor.
   - View upcoming appointments in a table format.

5. **Bed Availability Module**
   - Show total, occupied, and available beds using a simple counter.
